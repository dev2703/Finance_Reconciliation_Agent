An automated Account Reconciliation Agent

The architecture is based on deterministic rules, graph based learning, ML algorithms & LLM tool fallback

Problem: Closing Books is a big headache for CFOs. An automated system that does all the heavy lifitng for them and works most of the time with human in loop

Use UV as package manager create virtual environments run uv add -r requirements.txt for all the required packages and it would install all dependencies locked in pyproject.toml file
